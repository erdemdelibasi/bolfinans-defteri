# Bol Finans Defteri

@BolFinans YouTube kanalının videolarında sözlü olarak "aldım" / "sattım" dediği
her noktada o varlığa 1.000 $ yatırılmış gibi kurulmuş, **kağıt üzerinde** bir
portföy simülasyonu. Sayfa açık kaldığı sürece fiyatları kendisi tazeler.

**Yatırım tavsiyesi değildir.** Hiçbir gerçek emir verilmedi, hiçbir hesap
kullanılmadı. Kamuya açık yorumların geriye dönük bir simülasyonudur.

`index.html` tek başına yeterlidir; dışarıya tek bağımlılığı fiyat beslemeleri
(TradingView, Binance) ve Google Fonts'tur. Sayfa, defteri tutan projenin
(`BolFinans-Defteri`) `build_live.py` betiğiyle üretilir — burada elle
düzenlenmez.
